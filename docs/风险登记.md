# 风险登记: 风险与阻塞登记表

依据 `evidence-driven-engineering` 规范，对工程中识别出的风险、可能影响及对应处置预案进行台账化管理。

---

## 风险清单

| 风险 ID | 风险描述 | 触发条件 | 影响范围 | 缓解与处置预案 | 当前状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RSK-01** | Windows PowerShell 脚本执行策略受限 (ExecutionPolicy) | 用户直接在终端调用没有 `.cmd` 后缀的 npm/pnpm | 命令报错无法运行 | 脚本与构建统一明确调用 `npm.cmd` 或通过 `powershell -ExecutionPolicy Bypass` 执行 | 🟢 已缓解 |
| **RSK-02** | 本地服务端口 3456 冲突 | 系统中已运行其他本地代理或原版 Claude Code | Server 无法绑定端口报错退出 | 支持通过环境变量 `SERVER_PORT` 或命令行参数覆盖默认端口 | 🟢 已缓解 |
| **RSK-03** | Windows HTTP/1.1 Socket 空闲连接超时 | 客户端与 `Bun.serve` 长时间保持连接但未传输数据 | Windows 常见网络断开重连 | `Bun.serve` 显式设置 `idleTimeout: 0` 禁用空闲关闭，客户端实现指数退避重连机制 | 🟢 已缓解 |
| **RSK-04** | 文件修改并发冲突与竞态破坏 | 模型单轮连续产出针对同一文件的多次写调用 | 代码错乱或丢失最新改动 | `ToolOrchestrator` 强制将所有写工具与破坏性工具串行化，仅允许只读工具并发 | 🟢 已消除 |
| **RSK-05** | 外部 LLM API 欠费、超时或网络中断 | 用户未配置 API Key 或网络连不上 OpenAI/Claude | Agent 执行挂起或报错 | 内置 `MockLLMProvider` 用于纯离线测试；真实请求配置 30s 熔断与超时拦截 | 🟢 已缓解 |
