# 交接手册: 交接与恢复状态说明书

依据 `evidence-driven-engineering` 规范，本文件确保在任何 Agent 或工程师接手时，不依赖对话历史即可完整还原进度与继续开发。

---

## 1. 系统核心入口指南

| 模式 | 启动命令 | 入口文件 | 说明 |
| :--- | :--- | :--- | :--- |
| **CLI 命令行模式** | `bun run bin/agent-cli` | `bin/agent-cli` | 独立控制台交互，支持纯终端快速任务执行 |
| **本地 Server Sidecar** | `bun run src/server/index.ts` | `src/server/index.ts` | 独立启动 `Bun.serve` REST 与 WebSocket 网关 |
| **全套自动化测试** | `bun test tests/` | `tests/` | 运行 7 项核心架构测试（120ms 瞬启） |
| **桌面客户端开发态** | `npm.cmd run dev` | `src/renderer/` & `src/main/` | 启动 Electron 桌面应用，内置 HMR 与自动 Sidecar 拉起 |
| **全端生产打包** | `npm.cmd run build` | `electron-vite build` | 编译桌面前端与主进程产物至 `out/` |

---

## 2. 状态与存储位置
- **SQLite 数据库**: `~/.claude-agent/agent.sqlite`
- **本地配置文件**: `~/.claude-agent/config.json`
- **工作区 Skills**: `d:/Agent/.agents/skills/`
